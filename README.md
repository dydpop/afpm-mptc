## 一、项目简介

赛车电驱要求高转矩密度、快响应与紧凑的轴向尺寸，轴向磁通永磁电机（AFPM）因功率密度高、体积利用充分而被视为电推进的合适候选。但高功率密度意味着更高的损耗密度，车载散热受限使绕组与永磁体温度升高，定子电阻与永磁磁链随工况漂移；而模型预测转矩控制（MPTC）恰恰依赖这些参数预测未来状态。

本项目不主张填补方法层面的空白，而是针对上述场景完成一次**可复现的定量验证**：在同一台电机、同一套工况下，量化参数失配对 MPTC 性能的影响，并给出初步的适用边界。

**核心假设**：在相同失配比例下，MPTC 的稳态性能退化幅度大于 PI 矢量控制，且永磁磁链失配的影响强于电感失配。若实测两者退化差异不显著、或电感失配影响占优，则假设不成立。

## 二、方法概要

| 环节 | 做法 |
|---|---|
| 被控对象 | 以已发表 AFPM 样机参数建立 Simulink 模型（Rs=0.2 Ω、Ld=Lq=8.5 mH、ψf=0.175 Wb、p=4、Udc=250 V），不涉及电磁设计 |
| 控制策略 | MPTC：每周期枚举 6 个非零矢量与 2 个零矢量，三项代价函数（转矩误差 + 磁链误差 + 开关累计次数）择优输出，含一拍延时补偿，采样周期 100 μs |
| 对照方案 | PI 矢量控制为基准对照；直接转矩控制视进度增设 |
| 评价指标 | 转矩阶跃响应时间、稳态转矩脉动峰峰值、定子电流 THD、等效平均开关频率 |
| 参数摄动 | 电阻 / d-q 电感 / 永磁磁链各取 0、±10%、±20% 五点扫描，先粗扫后按拐点加密 |

## 四、为什么这样分工

**1. 组长不承担技术模块，是为了让"进度"有人管**

项目管理本身是交付物——报告要统稿、进度要跟踪、风险要上报，这些活不产出代码但必须有人做。如果组长同时扛一个关键模块，一旦模块卡住，进度就没人盯了。所以组长承担参数体系核定（需要通读文献、核对全部参数，工作量可控但必须准确）与全部文档输出，技术模块分给四位成员。

**2. 建模与算法由两人专职承担，因为它们是关键路径**

整个项目只有两条真正的长链：模型能不能建对、算法能不能闭环。这两条任一卡住，后面的对照、扫描、出图全部停摆。因此这两项各配一个专职负责人，不与其他任务混编。其余三人围绕这两条链提供支撑。

**3. 对照与数据分设两人，是为了让"测量口径"和"批量执行"不冲突**

指标测量脚本的设计需要静下来想清楚口径（比如等效开关频率怎么统计才公平），而参数扫描是重复性的批量劳动（30 次仿真、命名、存档）。两者性质不同，合在一人身上会导致口径没想清楚就急着跑批。分开后，Bokun Tian负责"怎么算才对"，Yuxuan Lu负责"按口径跑全部"。
