## 运行顺序

在仓库根目录启动 MATLAB R2024b：

```matlab
addpath('src/matlab');
run_research('all');      % 测试-标称-扫描-消融-出图，一次跑完并校验批次完整性
summarize_research;       % 逐文件核验原始数据后生成验收与敏感性摘要
addpath('src/model');
validate_baseline;        % 独立 Simulink 电机方程交叉验证
```

入口：[run_research.m](../src/matlab/run_research.m)。实现口径变更见 [INTERFACE.md](../src/INTERFACE.md)，本轮结论与证据边界见[研究验证记录](研究验证记录.md)。

旧版 `data/sweep_results.csv` 和根部旧图保留历史溯源，**不作为修正后结论证据**。新结果统一进入 `data/research_v2/` 与 `figures/research_v2/`。
