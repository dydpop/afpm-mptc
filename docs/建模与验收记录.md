## 坐标和预测方程

采用幅值不变 Clarke 变换，α 轴与 A 相轴重合，三线制下 iα = ia，iβ = (ib − ic)/√3。d 轴沿转子永磁磁链，电角度以 A 相轴为零点，θe = pθm，ωe = pωm。

- Park 变换：id = iα cosθe + iβ sinθe，iq = −iα sinθe + iβ cosθe。
- 电机磁链：ψα = L iα + ψf cosθe，ψβ = L iβ + ψf sinθe。
- 电磁转矩：Te = 1.5 p(ψα iβ − ψβ iα) = 1.5 p ψf iq。
- 机械方程：J dωm/dt = Te − T_load − Fωm。正负载转矩阻碍正向旋转。机械转速 n = 60ωm/(2π)，单位 r/min。
- 控制端离散磁链预测：ψαβ[k+1] = ψαβ[k] + Ts(vαβ[k] − Rs iαβ[k])。按 θe[k+1] ≈ θe[k] + Ts pωm[k] 更新永磁磁链方向，由 iαβ[k+1] = (ψαβ[k+1] − ψf[cosθe[k+1], sinθe[k+1]])/L 恢复电流，再用叉乘式求 Te[k+1]。独立电机模型使用连续积分，仓库控制器可单独选择预测形式。

## 模型接口

输入为 `g`（六路 0/1 门极，A+/A−/B+/B−/C+/C−）、`T_load`（N·m）和 `w_ref`（r/min，供测试接口保留）。模型接受每桥臂上下管互补的理想开关输入。转速闭环由外部控制器实现。

输出为 `i_abc`（A）、`idq`（A）、`w_r`（机械 rad/s）、`theta_e`（电角 rad）、`T_e`（N·m）、`psi_ab`（Wb）和 `Vdc`（V）。

## 验收结果

**独立 Simulink 模型。** 初值为零、负载为零，施加门极 [1,0,0,1,0,1]，静止 α 轴电压为 2Vdc/3。1 ms 时输出三相电流 [19.378961, −9.689481, −9.689481] A，与 RL 解析解相符，最大绝对误差小于 10⁻⁵ A。电磁转矩绝对值小于 10⁻⁸ N·m。

**空载与加载波形。** 采用仓库 PWM FOC 数值闭环作为测试环境，给定转速 300 r/min，控制周期 50 μs，总时长 2 s。加载工况于 0.3 s 施加 8 N·m。以下按 1.6–2.0 s 的控制周期样本统计。

| 工况 | 平均转速 r/min | 相对误差 | ABC 相基波峰值 A |
|---|---:|---:|---|
| 空载 | 299.998745 | −0.000418% | 0.23981 / 0.23924 / 0.23976 |
| 8 N·m 加载 | 299.894938 | −0.035021% | 7.8588 / 7.8587 / 7.8588 |

空载三相基波按电角拟合的相位为 89.929°、−30.008°、−149.920°，相间约 120°，基波峰值最大差约 0.00057 A。PWM 波形含开关纹波。加载后稳态转速误差满足小于 2% 的要求。上述波形来自仓库数值闭环，独立 SLX 的解析测试见上段。
