# 本轮研究验证记录

## 目的与范围

依据正式开题继续完成一个可复现的小型科研阶段：在同一集中参数电机与负载工况下，比较参数估计偏差对 MPTC 和 PI 矢量控制实现的影响。不是为了把开题假设证明为真，而是允许结果支持、削弱或否定它。

本轮只覆盖 300 r/min 给定、0.3 s 从零加载至 8 N m、1.2 s 总时长。8 N m 不是额定 11.9 N m；尚不代表赛车整车、温升/饱和、弱磁或硬件实机性能。已核对最终 DOCX 内容，但未改老师模板。

## 先修问题，再作比较

1. **FOC公平性**：旧程序直接施加连续电压，不能与MPTC离散开关比较纹波。改为同一250 V两电平逆变器、真实PWM与实际桥臂边沿计数。
2. **实际一拍延时**：本周期施加pending命令，周期结束再更新；MPTC补偿开关仅改变预测，不能删除物理延时。
3. **外环与量纲**：两方案用同一转矩单位速度PI、1.5倍额定转矩限幅、条件积分反饱和。FOC将转矩按估计磁链换算iq给定。
4. **指标**：响应采用持续稳定判据；负载扰动速度恢复不冒称直接转矩指令阶跃。THD取最后5个完整电周期的2—40次谐波，直流与基波单独处理；宽带残差另列。无效测量保留NaN和原因，不填零。
5. **启动相位边界**：真实启动停转会产生重复相位。插值域限制在已验证的单调稳态窗口，并加回归测试。
6. **权重不能想当然**：标称候选磁链权重0.05/0.5/1/2中，原0.05导致很大的d轴摆动；选1后冻结，再做失配扫描。不是全局最优权重，不按失配结果调参。
7. **数值细化**：第一轮中点PWM的FOC Nsub20→40，转矩峰峰值1.1455→1.0319 N m、THD0.2390→0.1331%，未过收敛筛查。因此最终对照必须用精确载波交点分段积分重跑，不能沿用第一轮数值。

## 实验协议

- 真实电机：Rs=0.2 ohm、L=8.5 mH、psi=0.175 Wb、p=4、Udc=250 V。开题引用样机文献，本轮未重新逐项核对文献原文。J=0.003 kg m²、F=0.008 N m s及控制增益属于研究假设/整定。
- 真实对象始终不变；失配仅改控制器估计参数。Rs、L、psi各用0.8/0.9/1/1.1/1.2倍率，两方案共30行，去重后为26个配置。
- FOC的Kp=L_est×400、Ki=Rs_est×400和前馈都随估计值配置；因此不是“固定PI增益、只改前馈模型”的试验。结果表保存增益。
- 控制周期50 us；与开题100 us有差异，另做50/100 us延时补偿消融。plant记录步长=Ts/Nsub；Nsub10/20/40细化。
- 磁链/开关权重1/0.02，标称后冻结。FOC载波仅按标称MPTC的实测开关频率校准一次，此后固定；失配点不保证等开关频率。
- 末0.4 s为统一稳态指标窗；THD使用其中最后5个完整电周期，并要求速度峰峰变化<2%、原始采样带宽可辨识40次谐波。有效标记不是数值收敛证明。
- 附加id峰值和相A峰值来自控制步采样，不是三相最大值或模拟带宽峰值，不用于器件电流额定值验收。
- MPTC使用alpha-beta电流Euler预测并代数恢复磁链；不是独立磁链积分观察器。plant用RK4，独立Simulink方程验证另用连续积分器。

## 验证与结果

最终批次 `run_20261116_000759`（源码指纹 f1be2a4c…8db3）已完整跑完并通过门禁：核心回归12/12、指标测试22/22、Simulink方程校验15/15、扫描30行（26个去重配置）、消融17行、数值细化筛查8/8、30行平均转速误差全部<2%、THD 30/30有效。

**标称工况（8 N m负载，末0.4 s窗口）**

| 方案 | 平均转速 | 转矩脉动 p-p | THD(2–40次) | 实测器件开关频率 | 负载恢复 |
|---|---:|---:|---:|---:|---:|
| MPTC | 297.38 r/min | 1.217 N m | 2.849% | 1332.1 Hz | 469.6 ms |
| 真实PWM FOC | 297.40 r/min | 0.955 N m | 0.080% | 1332.5 Hz | 467.1 ms |

两方案外环、母线、延时与开关计数口径相同；开关频率按标称点校准到差0.03%以内。

**参数失配（相对标称的最大变化，倍率0.8–1.2）**

| 参数 | MPTC 脉动变化 | FOC 脉动变化 | MPTC THD变化(百分点) | FOC THD变化(百分点) |
|---|---:|---:|---:|---:|
| Rs | +12.9%（0.156 N m） | +0.03% | +0.05 | +0.001 |
| L | +27.8%（0.339 N m） | +0.28% | +0.21 | +0.010 |
| psi | +37.9%（0.462 N m） | +0.34% | −0.11 | +0.034 |

**对两条开题假设的证据判断**

1. “同等失配比例下MPTC稳态退化大于PI矢量控制”——在转矩脉动上**方向一致且量级差距很大**（MPTC 13%–38%，FOC ≤0.35%），在本工况/本实现下支持该假设。但只能限定为脉动与电流谐波两项，且FOC自身有速度外环在工作，不能读成“FOC对参数不敏感”。
2. “磁链失配影响强于电感失配”——脉动最大变化 psi 37.9% > L 27.8% > Rs 12.9%，**方向支持但两者只差约10个百分点**，属于弱支持而非显著结论；且psi=0.8与L=1.2时MPTC的d轴电流峰值从2.56 A涨到32–34 A、开关频率掉到770–885 Hz，说明这部分退化含开关行为改变，不能全部归因于预测误差。

**机制线索**：磁链估计偏小时，代价函数的磁链项驱动明显d轴偏移（id峰值约32 A），同时翻转惩罚抑制开关、频率下降，脉动随之上升；磁链估计偏大时反而脉动下降但开关频率上升到1409 Hz。这提示MPTC的真实风险不止“脉动变大”，还有电流应力与开关损耗重新分配，后续应把id峰值和损耗纳入指标。

**延时补偿消融**：无补偿 50 us 脉动3.43 N m、100 us 6.91 N m；有补偿降至1.22 / 2.28 N m（降64% / 67%）。补偿在两种控制周期下都带来实质改善，方向与开题预期一致。

**权重与失稳**：开关权重0.05导致转速掉到154.8 r/min、脉动43.1 N m，是**失败候选**，不可当作可行工作点；磁链权重0.05/0.5的THD为111%/19.8%（d轴大幅摆动），1为标称，2虽脉动升到5.80 N m但稳定。这支持“权重必须整定并记录”，也说明标称1不是全局最优。

**数值细化**：Nsub 20→40的相对变化，MPTC四个指标均在1e-7量级，FOC脉动0.21%、THD 0.0096%、频率与转速0%，8/8项过5%筛查。修正前的“中点采样PWM”版本FOC脉动变化达9.9%，已被本轮取代，不再作为证据。

独立Simulink验证：真实4状态连续Integrator模型，旋转电压与对齐直流两种激励；与高精度ode45及RL解析解比较，15个信号/参考检查通过。最大绝对误差5.34e-10，最大归一化误差1.10e-11；证明这些方程实现一致，不证明真实样机准确，也不是完整控制闭环验收。

## 如何读图

- `baseline_comparison.png`：共同对象、外环与延时下的速度/转矩/相A电流；转矩与电流曲线按控制步显示，精细统计来自fine记录。
- `mismatch_sensitivity.png`：按Rs/L/psi分列，观察纹波、THD、负载恢复与实际开关频率；必须联看频率，不能把降频伴随的纹波变化单独归为鲁棒性。
- `robustness_checks.png`：左侧时间步细化，右侧开关权重的频率/纹波关系。失稳候选保留，不能拿它冒充可行的最优权衡。

## 统计和结论边界

这是确定性仿真扫描，不是独立随机重复试验。三个参数的标称点重复，不以30行为样本量做p值或置信区间。给出实际数值、相对标称变化与绝对变化，不声称“显著”。FOC低THD基准的相对百分比可能放大，必须同时看百分点变化。

候选结论应限制为“在本工况/参数/实现下观察到”；不能写“全面优于”“所有失配下均更差”“已验证赛车适用性”。负载恢复与直接转矩阶跃是两种不同验收，不可替换。
