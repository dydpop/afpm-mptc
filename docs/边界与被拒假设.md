# 边界与被拒假设

> 一页纸，供结题报告"讨论"一节与答辩问答直接取用。每条都注明依据，不写没有数据支撑的判断。

## 一、结论的适用范围

1. **对象**：文献小功率 AFPM 样机（300 r/min 基速、11.9 N·m），非赛车级电机。所有"赛车工况"特征仅由升速（150→300 r/min，0.6 s）与电压受限（150 V/1800 r/min）两处工况体现。
2. **工况谱**：主结论建立在额定转速、8 N·m 负载、单一权重上，另有三段工况与 30 行失配扫描支撑。**不外推到宽转速、宽负载或实车**。
3. **手段**：纯仿真，无台架。这不是缺陷，是开题已明确的课题设定（"全部采用仿真验证"）。

## 二、被数据否定的两个初始判断

| 初始判断 | 实测结果 | 处理 |
|---|---|---|
| 期望"磁链积分形式整体更优" | 对 L 免疫（id 峰值 33.6→2.6 A），但对 ψ 敏感（ψ×0.8 脉动 1.60→9.79 N·m），敏感性被 1/L 放大 | 改写为"两种形式把鲁棒性押在不同参数上"，不作单向优劣判断 |
| 初判"磁链带过紧导致分层代价 THD 高" | 反之：转矩带固定 5%、磁链带 5→20→50% 时 THD 5.35→15.23→20.13% | 采信诊断，机理改写为"磁链带越松、磁链越飘、电流越差" |

## 三、参数与权重的可行性边界（不是"最优值"）

**λf（磁链权重）**：0.05/0.5 时 d 轴电流 93.9/54.5 A（磁链失控），2.0 时不满足准稳态；λf=1 是"磁链不失控且转矩可控"的可行点。

**λsw（开关权重）**：0 → 2081 Hz；0.02 → 1344 Hz（与 FOC 载波对齐）；0.05 → 失稳。选 0.02 是为满足"等开关频率比较"这一前提，不是为优化脉动。

**J（转动惯量，估计值）**：J 变化 4 倍，恢复时间仅变 4%、脉动 1.5%——恢复时间由转速外环整定主导。J 不影响结论，标注来源即可。

## 四、口径上的固有局限（必须与结果同报）

1. **谐波口径与开关频率耦合**：2–40 次只反映低次畸变；2–200 次才覆盖本项目 1.3 kHz 开关分量（MPTC 2.87→4.46%）。10 kHz 载波时 FOC 主峰移出 200 次窗口，跨协议不可直接比。
2. **开关频率必须并列**：L/ψ 失配点 MPTC 开关频率从 1344 掉到 764–775 Hz，脉动上升中含降频贡献。
3. **稳态判据影响量级**：加入稳态门禁后 Rs 失配影响由 +12.9% 降到 +1.9%。
4. **分层代价需容差设计**：固定带宽下无一组全面占优（2% 带脉动 0.900 N·m 但 THD 18.6%），文献[7]的容差序贯依赖自适应设计，本实现未做。

## 五、答辩预案（三条最可能被问到的）

1. **"为什么不用 100 μs / 10 kHz？"** 按开题口径复核过：该设定下 MPTC 开关频率仅 682.5 Hz、FOC 10000 Hz，相差 14.6 倍，不可比。主基准用 50 μs 并把 FOC 载波校准到 1344 Hz，是为满足"等开关频率"比较前提。
2. **"结论能推广吗？"** 趋势稳健（30 行扫描 + 拐点加密 + 双口径谐波 + 两种预测形式交叉验证），但对象与工况有限，数值不外推。
3. **"和实物对得上吗？"** 无台架；方程层面用独立连续积分模型校验 15/15，实现层面用全离散闭环与脚本比对到 1e−10。
