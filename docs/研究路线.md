# 研究路线与判定标准

> 用途：把"接下来做什么"变成可验收的条目，避免做到哪算哪。每条都写明**判据先定、结果后看**。

## 一、研究问题卡

| 项 | 内容 |
|---|---|
| 问题 | 在同一台 AFPM 等效集中参数电机、同一工况与同一开关频率口径下，控制器内部参数偏差（Rs、L、ψf）对 MPTC 与 PI 矢量控制的稳态与动态性能影响各多大？ |
| 假设1 | 同等失配比例下，MPTC 的稳态退化幅度大于 PI 矢量控制 |
| 假设2 | 永磁磁链失配的影响强于电感失配 |
| 证伪条件 | 若 MPTC 与 FOC 的退化差异落在同一量级（例如都 <5%），或电感失配影响≥磁链失配，则假设不成立，须如实写出 |
| 边界 | 仅仿真；集中参数等效；不含温升、饱和、三维磁场；单转速（300 r/min）为主，弱磁另列为延伸 |
| 非目标 | 不主张算法创新，不主张赛车实车适用性 |

## 二、指标与门槛（先定后用）

| 指标 | 定义 | 有效前提 |
|---|---|---|
| 转矩脉动 p-p | 稳态窗内 max−min（fine 采样，2.5 µs） | 稳态门通过 |
| THD | 末 5 个完整电周期、2–40 次谐波、相位同步积分 | 稳态门通过且 Nyquist 可辨 40 次 |
| 平均开关频率 | 三桥臂翻转数/(6×窗长)，按实际边沿计数 | 整数边沿且窗口边界对齐 |
| 负载恢复 | 转速回到 ±2% 并保持 ≥20 ms | 有有效负载阶跃 |
| 转矩阶跃响应 | 1 ms 均值进入 ±5% 目标并保持 ≥20 ms | 速度环旁路、直接给 Tref |

**稳态门**：窗口内转速线性趋势造成的相对变化 ≤0.2%，且窗口均值与给定偏差 ≤0.5%。不通过则该窗的 THD 置无效、脉动标 `ripple_valid=false` 但保留数值。

## 四、风险与对策

- **速度环偏慢**：Kp=2、Ki=8 对应慢极点约 4 rad/s（τ≈0.25 s），加载后约 1.7 s 才收敛。对策：观测延长至 2.0 s 并把稳态度量化为门禁；若后续需要更快工况切换，再单列一版整定并对比，不在同一批里混用。
- **失配点开关频率不等**：FOC 载波按标称点校准后固定，MPTC 实际频率随失配漂移（实测 770–1409 Hz）。对策：所有失配结论并列报出开关频率，不把降频带来的脉动变化单独归因于预测误差。
- **FOC 的速度外环会补偿稳态偏差**：因此"FOC 脉动几乎不变"不等于"FOC 对参数不敏感"。对策：结论限定在脉动与电流谐波，并补报电流幅值/利用率。
- **单次确定性仿真无重复**：不做显著性检验，只报数值、相对与绝对变化。
- **预测器与对象精度混用**：plant 为 RK4 子步，MPTC 预测为冻结转速离散；对策：用 Nsub 细化 + Euler/梯形对照分别界定两侧误差。
