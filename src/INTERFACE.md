# 模块接口定义与任务拆解

> 目的：让五个人的模块能直接对接，不出现"信号名对不上""单位不一致""采样率不同"这类返工。
> 规则：**任何人改端口名、单位、采样率，必须先改这份文档并通知全员。**

---

## 一、总体信号流

```
                 ┌──────────────┐
   T_e*, ψ_s* ──▶│   mptc.slx   │──g[6]──┐
                 │  (或 foc.slx) │         │
                 └──────────────┘         ▼
                        ▲            ┌──────────────┐
                        │            │ baseline.slx │
      i_abc, θ_e, ω_r ──┴────────────│  (电机+逆变器)│
                                      └──────────────┘
                                             │
                                      logsout（波形）
                                             ▼
                                      metrics.m（指标）
                                             ▼
                                      sweep.m（批量）
```

`main.slx` 只做两件事：把控制器的 6 路信号接到电机逆变器、把测量信号引出到 `logsout`。**里面不放任何控制逻辑。**

## 二、模型接口

### 2.1 `baseline.slx`（Haotian Feng）

| 方向 | 信号名 | 维度 | 单位 | 说明 |
|---|---|---|---|---|
| 输入 | `g` | 6 | 0/1 | 六路门极信号，顺序为 A+/A−/B+/B−/C+/C− |
| 输入 | `T_load` | 1 | N·m | 负载转矩，正值为阻转矩 |
| 输入 | `w_ref` | 1 | r/min | 转速给定（仅测试用，联调时由控制器给） |
| 输出 | `i_abc` | 3 | A | 三相定子电流 |
| 输出 | `idq` | 2 | A | d/q 轴电流（按 A 相轴对齐计算） |
| 输出 | `w_r` | 1 | rad/s | 机械角速度 |
| 输出 | `theta_e` | 1 | rad | 电角度，**以 A 相轴为零点** |
| 输出 | `T_e` | 1 | N·m | 电磁转矩 |
| 输出 | `psi_ab` | 2 | Wb | 定子磁链 α/β 分量 |
| 输出 | `Vdc` | 1 | V | 直流母线电压 |

**硬约束**：所有 Outport 的名称必须和上表完全一致，`main.slx` 靠名字接线。

---

### 2.2 `mptc.slx`（Wenkai Liu）

| 方向 | 信号名 | 维度 | 单位 | 说明 |
|---|---|---|---|---|
| 输入 | `i_abc` | 3 | A | 来自 baseline |
| 输入 | `theta_e` | 1 | rad | 来自 baseline |
| 输入 | `w_r` | 1 | rad/s | 来自 baseline |
| 输入 | `Vdc` | 1 | V | 来自 baseline |
| 输入 | `T_ref` | 1 | N·m | 转矩给定 |
| 输入 | `psi_ref` | 1 | Wb | 定子磁链给定（按 ψf 确定） |
| 输出 | `g` | 6 | 0/1 | 门极信号，顺序同 baseline |

**采样约定**
- 控制器内部采样周期 `Ts_ctrl = 100e-6`（10 kHz）
- 用 `Rate Transition` 或触发子系统实现，不要靠求解器步长
- 仿真求解器固定步长 `Ts_sim = 1e-6`，功率电路用 `powergui` 离散化

**内部结构约定**（便于对照）
```
mptc.slx
├── 测量变换（abc→αβ）
├── 延时补偿（存上一拍实际矢量）
├── 预测模型（αβ 离散）
├── 8 矢量枚举
├── 代价函数（三项）
└── 输出保持（零阶保持到下一拍）
```

---

### 2.3 `foc.slx`（Bokun Tian）

输入输出端口**与 mptc.slx 完全一致**，这样才能在 `main.slx` 里直接互换（用 Variant Subsystem 或手动替换）。

内部照课件原始结构，只改：参数统一、采样周期改成 100 μs。

---

### 2.4 `main.slx`（联调用，不归个人）

- 三个 Variant：`MPTC` / `FOC` / `DTC`（DTC 可选）
- 一个变量 `ctrl_mode` 切换
- 输出统一存 `logsout`，供 `metrics.m` 读取
- **任何人不得在此文件里加自己的逻辑**，只做连线

## 三、脚本接口

### 3.1 `metrics.m`（Bokun Tian）

```matlab
function m = metrics(logsout, opts)
% 输入  logsout : Simulink.SimulationData.Dataset
%       opts    : struct，含 t_step_ref（阶跃时刻）、t_ss（稳态窗口起点）
% 输出  m       : struct，字段如下
%   .t_rise     转矩阶跃响应时间 [s]，进入 ±5% 误差带
%   .ripple_pp  稳态转矩脉动峰峰值 [N·m]，0.1 s 窗口
%   .thd        定子电流 THD [%]，稳态一个基波周期
%   .f_sw_avg   等效平均开关频率 [Hz]
```

**调用示例**（负责人写进脚本注释）
```matlab
m = metrics(logsout, struct('t_step_ref',0.3,'t_ss',0.5));
```

口径定义见 `src/scripts/README.md`，**第 3 天前定稿，之后不改**。

---

### 3.2 `sweep.m`（Yuxuan Lu）

```matlab
sweep(cfg)
% cfg.mode     : 'coarse'（0/±10/±20）| 'fine'（按拐点加密）
% cfg.params   : {'Rs','Lq','psi'} 中选一个或多个
% cfg.cond     : 'step' | 'ramp' | 'fw'   工况
% 输出          : data/<param>_<offset>_<cond>.mat
```

每个 `.mat` 必须含三个变量：
```
params   : struct，记录本组实际参数
metrics  : struct，metrics.m 的输出
wave     : struct，关键波形（降采样到 1 kHz 存，避免文件过大）
```
