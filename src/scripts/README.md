## 指标口径（定稿后不再改动）

| 指标 | 定义 |
|---|---|
| 转矩阶跃响应时间 | 从给定跳变到实际进入 ±5% 误差带所需时间 |
| 稳态转矩脉动峰峰值 | 稳态段取 0.1 s 窗口，计算 max − min |
| 定子电流 THD | 取稳态一个基波周期，用 `thd()` 计算 |
| 等效平均开关频率 | 1 s 内六桥臂开关动作总次数 ÷ 6 ÷ 1 s |
